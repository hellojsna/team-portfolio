## 전체 화면 구성

웹사이트는 메인, 팀 소개, 프로필, 갤러리, 활동의 총 5개 페이지로 구성한다. 모든 페이지는 공통 메뉴바를 통해 이동할 수 있도록 설계하며, 페이지별 콘텐츠의 목적에 따라 레이아웃과 기능을 구분한다.

- **메인 페이지:** 팀을 대표하는 문구와 핵심 디자인 요소를 활용하여 첫 화면 구성
- **팀 소개 페이지:** 팀의 구성 목적, 프로젝트 방향 및 전반적인 소개 제공
- **프로필 페이지:** 팀원별 사진, 이름, 역할 및 자기소개 정보 제공
- **갤러리 페이지:** 팀 프로젝트 및 활동 관련 이미지와 시각 자료 제공
- **활동 페이지:** 팀의 주요 활동, 프로젝트 진행 과정 및 활동 기록 제공

## 페이지별 세부 기능

### 메인 페이지

- 팀을 대표하는 문구와 소개 메시지를 화면 중앙 또는 좌측에 배치
- 핵심 키워드가 순차적으로 변경되는 텍스트 애니메이션 적용
- 팀의 정체성을 표현할 수 있는 타이포그래피 중심의 디자인 구성
- 메뉴바를 통해 다른 페이지로 이동할 수 있도록 구성

### 팀 소개 페이지

- 팀의 구성 배경 소개, 추구하는 방향과 목표 설명
- 팀의 주요 특징 및 핵심 가치 소개
- 텍스트와 이미지 등을 조합하여 정보를 직관적으로 전달

### 프로필 페이지

- 팀원별 프로필 카드 구성
- 팀원 사진, 이름, 담당 역할 및 간단한 자기소개 표시
- 팀원별 정보를 일관된 레이아웃으로 배치

### 갤러리 페이지

- 팀/개인 프로젝트 관련 사진을 이미지 형태로 제공
- 이미지 썸네일을 활용한 그리드 레이아웃 구성
- 이미지 클릭 시 상세 정보 표시

### 활동 페이지

- 팀의 주요 활동 및 프로젝트 기록 제공
- 활동별 제목, 날짜, 내용 및 관련 이미지 표시
- 시간순 또는 카테고리별로 활동 내역 정리
- 프로젝트 진행 과정과 주요 결과물을 확인할 수 있도록 구성

## 공통 컴포넌트 및 리소스 설계

페이지마다 동일한 요소를 반복해서 구현하지 않고 한 번 구현한 것을 재사용할 수 있도록 공통 컴포넌트를 분리하여 관리한다.

### 공통 메뉴바

- 모든 페이지에서 동일한 메뉴바 사용
- 공통 컴포넌트 common.js 스크립트 기반
- 메뉴 선택 시 해당 페이지로 이동
- 현재 접속 중인 페이지를 시각적으로 구분
- 화면 크기에 따라 메뉴 배치가 변경되는 반응형 구조 적용

### 공통 파일 구성

- **common.js:** 메뉴바 생성 및 공통 인터랙션, 현재 페이지 표시 등 공통 JavaScript 기능 관리
- **common.css:** 메뉴바 및 기본 서체, 각종 색상 변수 등 공통 UI 요소의 스타일 선언
